The user requests a mobile-first Maya Collection experience closely matching their uploaded luxury perfume references: deep teal, gold, ivory, elegant headings, compact product cards, and bottom navigation. They reiterated that the brand name, illustrated category icons, branded crowned bottle, and gold stepped-pyramid footer logo should match the supplied artwork, not generic approximations. The welcome reference uses golden sunbeams and a full-height perfume photograph; the footer reference uses dark petrol teal and gold, not the brighter green-teal homepage.

**Why:** The supplied brief explicitly rejects generic dashboard styling, screenshot-as-background implementations, distorted branding, fake reviews, and unsupported payment claims.

**How to apply:** Preserve the existing shop and real catalog when making visual changes. The user explicitly chose “Keep catalog unchanged” when offered the three reference perfumes; do not seed sample products to fill an empty visual layout. Use “OUR STORE” and HOME / EXPLORE / WISHLIST / BAGS navigation. The reference-matched home uses “UNISEX”; retain compatibility with the existing Perfect category. Keep English, Kurdish Sorani, and Arabic with RTL support, without mirroring lettering in bottle artwork. Do not invent social profile URLs or store policies.

**Artwork fidelity:** Preserve the original supplied bottle and label pixels when preparing reference photos for live UI.

**Why:** An image-cleanup edit changed the reference's portrait aspect ratio and product placement despite preservation instructions. Exact artwork is a repeated user requirement.

**How to apply:** Use generated cleanup only for background areas, check output dimensions, and preserve original product artwork rather than stretching or trusting a regenerated bottle.
